# 🧠 Disease Prediction System

The **Disease Prediction System** is a simple and educational web application where users can input multiple symptoms (like *fever, cough, body pain*) and receive a basic diagnosis suggestion based on those symptoms. The project uses JavaScript to match symptoms with possible conditions.


---

## 🚀 Features

- 🔍 Input multiple symptoms at once
- 🧾 View disease predictions instantly
- 📊 Probability-based matching 
- 🖥️ Simple, intuitive user interface
- 🔐 No login required — open and free to use


---

## 🛠️ Tech Stack

| Technology | Purpose                |
|------------|------------------------|
| HTML       | UI structure           |
| CSS        | Basic styling          |
| JavaScript | Symptom logic & alerts |


---

🧪 How It Works
The user enters comma-separated symptoms in an input field.
The system checks the first symptom against a predefined JavaScript object (symptomDiagnosisMap).
A diagnosis message is shown based on the match.

javascript
const symptoms = "fever, cough";
const diagnosis = symptomDiagnosisMap["fever"];
